# Modernization of the CMD application

# Purpose : To create a modernized version of the Access based CMD application. 
# Goals: 
  1) Highlight modern application development & architecture skills
  2) Demonstrate technical ability and knowledge of the AWS ecosystem

# Background : 
CMD is an Access based application currently in use by the BC government to manage various aspects of the meat processing industry. There are 2 Access files in use : 1 Access database containing the database tables to store data, 1 Access file containing the client front-end and reports.
